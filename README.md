# 非官方版网易中国版 Minecraft 自定义标签规范标准



网易 Minecraft 官方在 3.10 版本的更新中添加了[自定义标签](https://mc.163.com/dev/mcmanual/mc-dev/mcguide/20-%E7%8E%A9%E6%B3%95%E5%BC%80%E5%8F%91/15-%E8%87%AA%E5%AE%9A%E4%B9%89%E6%B8%B8%E6%88%8F%E5%86%85%E5%AE%B9/18-%E8%87%AA%E5%AE%9A%E4%B9%89%E6%A0%87%E7%AD%BE.html)功能。

现在可以像 Java 版本一样添加 tag 来归一化各种物品，避免出现 100 个番茄，还互相不通用这种情况。

鉴于目前已有的部分开发者反馈，和自己的一些综合考量，这里设计一套自定义标签规范标准，方便各个开发者之间互相统一 tag。

### 原版标签

> 指基岩版本身就拥有的标签。

### 通用标签

> 指多个模组之间互相通用，并非本模组特有的内容。

统一以 `common`开头，比如 `common:apple`。

冒号后名词统一使用单数形式名词。复合词使用小写下划线分割，不添加额外内容。

- 正面案例：`common:apple`，`common:tin_plate`

- 反面案例：`common:apples`，`common:plate/tin`

### 专用标签

> 仅含有本模组特殊物品，或者特定几个模组专有内容的标签。

一般以自己模组的 id 作为命名空间，后接自己的类别名词，自己的类别名词看自己设计，仅遵循小写英文单词和下划线即可。

案例：`kaleidoscope_cookery:table`
